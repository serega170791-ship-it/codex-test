# 秉秀 AI 提示词管理工具

一个纯 HTML、CSS 和 JavaScript 的中文网页应用，用来管理视频生成提示词。无需安装框架、登录账号、连接数据库或调用外部 API。

## 第一阶段功能

- 添加提示词：填写名称、适用模型、正文和可选备注。
- 适用模型：可灵、Seedance、MiniMax H3、其他。
- 查看完整内容、编辑、确认删除、一键复制正文。
- 按模型分类筛选，显示各分类的数量。
- 使用浏览器 localStorage 保存，刷新页面后仍可查看。
- 适配桌面和手机，支持键盘操作与 Esc 关闭弹窗。

## 新手运行步骤

### 方法一：直接打开（最简单）

1. 将 `index.html`、`styles.css` 和 `app.js` 下载到电脑上的同一个文件夹，保持文件名不变。
2. 双击 `index.html`，使用新版 Chrome、Edge、Firefox 或 Safari 打开。
3. 点击“添加提示词”，填写名称、模型和正文，点击“保存提示词”。
4. 使用左侧模型分类筛选；每张卡片上可以查看、编辑、删除或复制正文。

直接打开文件时，不同浏览器对本地存储的支持可能不同。若页面提示无法保存，请使用下面的方法。不要在两种打开方式之间反复切换：它们可能使用不同的数据存储空间。

### 方法二：启动本地预览（推荐）

电脑需已安装 Python 3。在项目文件夹打开终端，运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 中如不识别 `python3`，可以改用：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

保持终端窗口打开，在浏览器访问 **http://localhost:8000**。关闭预览时，在终端按 **Ctrl+C**。

如果在云端终端执行，`localhost` 指的是云端机器，不是你的电脑。需要平台提供的端口预览功能才能从电脑访问；也可以将三个网页文件下载到电脑，按上述步骤运行。

## 数据保存说明

**数据只保存在当前浏览器中，不会上传到云端，也没有在线备份或跨设备同步。**

- 使用 localStorage，存储键为 `bingxiu-ai-prompts-v1`。
- 不同浏览器、浏览器用户配置、设备或网页地址（协议、域名、端口）使用各自的数据空间。请尽量使用固定的打开方式和地址。
- 清除网站数据会删除提示词；无痕模式关闭后，数据可能丢失。
- 复制按钮只复制提示词正文，不包含名称、模型和备注。浏览器拒绝自动复制时会展示可选中的正文，请使用 Ctrl+C（Mac 为 ⌘C）或长按复制。
- 删除需要确认，删除后无法恢复；重要提示词请自行复制到其他文档备份。
- 若存储权限被关闭、空间不足或已有数据损坏，页面会提示错误，不会把保存失败显示为成功；损坏的原数据不会被自动覆盖。
