# 秉秀 AI 提示词管理工具

一个纯 HTML、CSS 和 JavaScript 的中文网页应用，用来管理视频生成提示词。无需安装框架、登录账号、连接数据库或调用外部 API。

## 当前功能

- 添加提示词：填写名称、适用模型、正文和可选备注。
- 适用模型：可灵、Seedance、MiniMax H3、其他。
- 查看完整内容、编辑、确认删除、一键复制正文。
- 按模型分类筛选，显示各分类的数量。
- 使用浏览器 localStorage 保存，刷新页面后仍可查看。
- 导出全部提示词为 JSON 备份，导入时可合并或覆盖；覆盖需要二次确认。
- 适配桌面和手机，支持键盘操作与 Esc 关闭弹窗。

## 新手运行步骤

### 方法一：直接打开（最简单）

1. 将 `index.html`、`styles.css` 和 `app.js` 下载到电脑上的同一个文件夹，保持文件名不变。
2. 双击 `index.html`，使用新版 Chrome、Edge、Firefox 或 Safari 打开。
3. 点击“添加提示词”，填写名称、模型和正文，点击“保存提示词”。
4. 使用左侧模型分类筛选；每张卡片上可以查看、编辑、删除或复制正文。

直接打开文件时，不同浏览器对本地存储的支持可能不同。若页面提示无法保存，请使用下面的方法。不要在两种打开方式之间反复切换：它们可能使用不同的数据存储空间。

### 方法二：启动本地预览（推荐）

电脑需已安装 Python 3。在项目文件夹打开终端，运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 中如不识别 `python3`，可以改用：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

保持终端窗口打开，在浏览器访问 **http://localhost:8000**。关闭预览时，在终端按 **Ctrl+C**。

如果在云端终端执行，`localhost` 指的是云端机器，不是你的电脑。需要平台提供的端口预览功能才能从电脑访问；也可以将三个网页文件下载到电脑，按上述步骤运行。

## 数据保存说明

**数据只保存在当前浏览器中，不会上传到云端，也没有在线备份或跨设备同步。**

- 使用 localStorage，存储键为 `bingxiu-ai-prompts-v1`。
- 不同浏览器、浏览器用户配置、设备或网页地址（协议、域名、端口）使用各自的数据空间。请尽量使用固定的打开方式和地址。
- 清除网站数据会删除提示词；无痕模式关闭后，数据可能丢失。
- 复制按钮只复制提示词正文，不包含名称、模型和备注。浏览器拒绝自动复制时会展示可选中的正文，请使用 Ctrl+C（Mac 为 ⌘C）或长按复制。
- 删除需要确认，删除后无法撤销；有备份时可重新导入恢复。重要提示词请定期点击“导出数据”备份。
- 若存储权限被关闭、空间不足或已有数据损坏，页面会提示错误，不会把保存失败显示为成功；损坏的原数据不会被自动覆盖。

## 本地备份和恢复

### 导出备份

1. 在保存提示词的那个浏览器中打开本工具。
2. 点击提示词列表上方的 **“导出数据”**。
3. 在浏览器的下载列表中确认 `bingxiu-ai-prompts-时间戳.json` 已保存，妥善保留这个文件。

导出包含当前浏览器本工具的 **全部提示词**，不受当前模型筛选影响，也不会修改当前记录。编号、名称、模型、正文、备注及记录中已有的其他字段都会完整保留，包括换行和空格。空提示词库也可以导出。

### 导入备份

1. 点击 **“导入数据”**，再点击 **“选择文件”**，选中之前导出的 JSON 文件。
2. 等待页面显示“已检查”及记录数量。仅选择文件不会修改当前数据。
3. 选择一种方式，点击 **“开始导入”**：
   - **合并现有数据（默认）**：保留当前记录，加入备份中的不同记录。
   - **覆盖现有数据**：用备份完整替换当前记录，必须再点击 **“确认覆盖”**。建议先导出当前数据；空备份会清空当前记录，页面会明确提醒。
4. 看到完成提示后，核对列表数量，刷新页面确认记录仍在。

合并时，名称、模型、正文和备注四个字段完全一致的记录视为重复，即使编号不同也会跳过；重复导入同一备份不会持续增加记录。编号相同但四个字段有差异时，不覆盖旧记录，而是给导入的记录分配新编号并保留两条。备份内部的重复内容也按相同规则跳过；覆盖方式则按备份原样恢复。

导入先完整校验再保存，不会先清空数据。错误 JSON、缺失字段、未知模型、重复编号或不支持的备份版本会被拒绝。保存空间不足或权限被拒绝时，原数据保持不变，所选备份仍保留，可以重试。覆盖确认期间如其他标签页修改了数据，本次覆盖会取消，需重新确认。若原数据损坏，可通过有效备份的“覆盖现有数据”及二次确认恢复。

备份带有工具标识、格式版本、导出时间和记录数组；也兼容本工具原始 localStorage 的记录数组 JSON。支持 UTF-8 编码（含 BOM），文件最大 50 MB。名称最多 100 字符、正文最多 50000 字符、备注最多 10000 字符，与编辑表单限制一致。备份不会读取其他应用的 localStorage 数据，也不会上传任何文件。

### 换电脑时如何迁移

**需要同时带走网页文件和 JSON 备份，单独复制网页文件夹不会带走浏览器中的提示词。**

1. 在旧电脑上，用原来的浏览器和原来的网页地址打开工具，确认能看到全部提示词。
2. 如果正在升级旧版，把新版 `index.html`、`styles.css`、`app.js` 替换到原来的文件夹，保持文件名和打开地址不变，再刷新。保留原浏览器的网站数据；如果列表变空，先回到原来的地址和浏览器核对，不要用空备份覆盖已有备份。
3. 点击 **“导出数据”**，确认下载完成。将网页文件夹和这个 JSON 文件一起复制到 U 盘或新电脑。
4. 在新电脑打开工具，点击 **“导入数据”**，选择复制来的 JSON；空提示词库选择默认的 **“合并现有数据”** 即可。
5. 核对提示词、备注和数量，刷新确认仍然保存，再保留备份文件以便以后恢复。

### 如何下载更新后的网页

打开 [GitHub 仓库的 work 分支](https://github.com/serega170791-ship-it/codex-test/tree/work)，点击 **Code → Download ZIP** 下载整个项目。解压后，确认 `index.html`、`styles.css` 和 `app.js` 在同一文件夹，再打开 `index.html`。本地 HTTP 运行方法同上。

升级已有工具时，请先按上面的迁移步骤，将新版网页文件替换到原文件夹并保留原浏览器和打开地址，再导出 JSON 备份。GitHub ZIP 只包含网页源码和说明，不包含浏览器中的提示词数据；更换电脑时，还需要自行复制导出的 JSON 备份。
